# Big-Data-Summer-Institute-2024-UMich
A compilation of my work for the 2024 Big Data Summer Institute at the University of Michigan. Our project was titled, "Evaluating the Causal Effect of Receiving Transthoracic Echocardiography on 28-Day Mortality in MIMIC-III Intensive Care Unit Patients with Sepsis". I was a part of the Data Mining/Machine Learning Group.
